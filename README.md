# Hospital_Emergency_Room_Dashboard
Hospital Emergency Room Dashboard using Power Bi

This Power BI dashboard to analyze Emergency Room data, revealing key insights into patient flow, wait times, and resource allocation. 📊

Here are some highlights:
✨ Average Wait Time: 35.3 minutes
✨Average Patient Satisfaction: 4.99/10
✨Peak Times: Mondays, Saturdays, Tuesdays at 11AM, 7PM, 1PM, 11PM
✨Top Referrals: General Practice, Orthopedics
✨Patient Demographics: Adults (30-39) largest group

This dashboard provides valuable information for optimizing staffing levels, improving patient experience, and streamlining ER operations.

The dataset covers nine months (April 2023 -October 2024) and has recorded 9216 unique patients.
